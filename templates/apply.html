使用流程

  1. 在此页申请，获得服务器端口、ssh -R 命令和 Agent 提示词。
  2. 在远程电脑上执行命令，保持该 ssh 进程运行。
  3. 在服务器本机打开终端，把提示词粘贴给本地 Agent。
  4. 任务结束后终止远程电脑上的 ssh 命令；隧道到期或断开后端口自动回收。

默认仅回环策略下，只有服务器本机的 Agent 能连接隧道。全部地址和指定地址策略需要宿主机 sshd 允许非回环绑定。
